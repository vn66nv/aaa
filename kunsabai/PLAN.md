# Kunsabai — план работ (автономная сессия, 6 часов)

Цель: копия ГдеДПС / дпс.нет для Таиланда — мобильная PWA + полная версия для компьютера, только бесплатные сервисы.

## Этап 1 — функции карты (по скриншотам ГдеДПС)
- [x] Флажки «ДПС» и «!», нижняя панель метки, ✔/✖ с именем последнего проголосовавшего
- [x] Полная версия для компьютера (боковая панель)
- [x] Кнопка «следовать за мной» (стрелка, как в ГдеДПС) с отслеживанием позиции
- [x] Предупреждение о приближении к метке ДПС (звук + вибрация, радиус настраивается)
- [x] Группировка меток при отдалении (вся страна читаемо)
- [x] Автор может удалить свою метку

## Этап 2 — аккаунты и общая база (Supabase free)
- [x] Настоящий вход: e-mail-код (Supabase Auth OTP), имя пользователя, значок «проверенный»
- [x] Защита от спама: лимит меток на пользователя, один голос на метку на сервере
- [x] Живое обновление меток (Supabase Realtime), без перезагрузки
- [x] Пошаговая инструкция подключения Supabase

## Этап 3 — Таиланд

- [x] Поиск: подсказки по мере ввода, тайские и латинские названия

## Этап 4 — качество и выпуск

- [x] Конфиги для Cloudflare Pages / Netlify (альтернатива GitHub Pages для приватного репозитория)
- [x] Офлайн: кэш оболочки и последних меток
- [x] Проверка PWA (Chrome: устанавливается, manifest без ошибок)
